# Web_Tools

Навчальні вебінструменти до шкільного курсу математики.
Опубліковано: **https://vitalik-khomiak.github.io/Web_Tools/**

Кожен інструмент відповідає за один крок міркування — спостереження,
висування гіпотези, перевірку — і зупиняється там, де починається доведення.
Сторінки відкриваються з телефона за посиланням або QR-кодом; реєстрації
немає, дані нікуди не надсилаються, усе рахується у браузері.

## Що всередині

| Шлях | Що це |
|---|---|
| `index.html` | майстер-панель: список інструментів, пошук, QR-коди |
| `about.html` | про проєкт, принцип, як покликатися |
| `assets/tools.js` | **перелік інструментів** — єдиний файл, який треба правити, щоб додати новий |
| `assets/style.css` | спільні стилі й кольорові токени (світла й темна теми) |
| `assets/hub.js` | рендер панелі, пошук, вікно з QR |
| `assets/qr/` | QR-коди, згенеровані окремим скриптом |
| `tools/<id>/` | сам інструмент: `index.html` для учня, `vchytel.html` для вчителя |

## Наявні інструменти

- **Перерізи куба** (`tools/pererizy-kuba/`) — січна площина, яка не проходить
  через вершини: скільки сторін може мати переріз. Учнівська версія без
  відповідей; окремий пульт учителя з ходом уроку й таймером.

## Як додати новий інструмент

1. Створити теку `tools/<id>/` з файлом `index.html`.
2. Дописати картку в `assets/tools.js`.
3. Перегенерувати QR-коди (скрипт лежить поза цим репозиторієм, у робочій
   теці проєкту).

## Ліцензія й використання

Матеріали відкриті для вчителів: користуватися на уроках, показувати на
проєкторі, давати учням посилання або QR-код можна вільно, з покликанням
на джерело.

Розроблено в межах магістерської роботи «Інформаційні технології як засіб
розвитку просторового та логічного мислення учнів у шкільному курсі
математики». Автор — Хом'як Віталій Юрійович.
